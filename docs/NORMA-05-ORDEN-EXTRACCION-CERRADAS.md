# NORMA 05 — Orden de extracción de convocatorias cerradas

**Vigente desde:** 2026-11-13. **Jerarquía:** subordinada a NORMA 00 y a los contratos de la base de datos v3.

1. Se extraen primero las convocatorias cerradas con **número de convocatoria más alto**, descendentemente (más reciente a más antigua). Se contrasta con el orden visual de la hoja, de arriba hacia abajo.
2. Cada **código distinto** cuenta como una convocatoria. Si aparece en varias filas o versiones, **todas** sus apariciones y documentos se conservan en el mismo expediente. La repetición no se usa para completar artificialmente el cupo de un lote.
3. Los lotes documentan sus extremos, posición en la tabla y código siguiente. Antes de cada interacción se revisa lo registrado para evitar omisiones y repeticiones injustificadas.
4. Este orden es exclusivamente operativo. Nunca permite omitir documentos, marcar fuentes no observadas como ausentes ni reconocer como validadas convocatorias que no superaron A–E.

**Corte histórico de esta primera ejecución v3:** 36 convocatorias abiertas y 60 cerradas (`2026-C2368` a `2026-C2286`), tres lotes de extracción de IA. Continuidad de cerradas: `2026-C2285` (fila 63 en el corte utilizado).
