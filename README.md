# Revisión de convocatorias — proyecto conceptual vigente

**Estado actual:** definición conceptual. Esta rama no contiene una implementación activa.

El objetivo es desarrollar una herramienta documental para comprender, integrar, estandarizar, comparar y verificar convocatorias de estudiantes auxiliares de la Universidad Nacional de Colombia, inicialmente Sede Bogotá. El principio rector es la **integridad y validación de la información**, con la base conceptual como núcleo y la extracción y visualización subordinadas a su contrato.

## Documentación de consulta obligatoria

1. [Propósito y objetivos](docs/01-PROYECTO-Y-OBJETIVOS.md).
2. [Principios, normas y validación A–E](docs/02-PRINCIPIOS-Y-NORMAS.md).
3. [Modelo conceptual de información](docs/03-MODELO-CONCEPTUAL.md).
4. [Experiencia y pruebas de aceptación](docs/05-EXPERIENCIA-Y-ACEPTACION.md).

No se seleccionarán tecnologías ni se implementará código antes de demostrar, con expedientes reales, que el modelo representa íntegramente fuentes, requisitos, perfiles, criterios, evaluaciones y resultados.
