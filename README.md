# Revisión de convocatorias — reinicio conceptual

**Estado: proyecto reiniciado desde su planteamiento. No existe una implementación activa en esta rama.**

El proyecto busca desarrollar una herramienta especializada para **comprender, integrar, estandarizar, comparar y verificar** convocatorias de estudiantes auxiliares de la Universidad Nacional de Colombia, inicialmente Sede Bogotá. Se propone convertir documentos dispersos en información **completa, relacionada y verificable**, sin alterar los originales ni sustituir la evidencia por resúmenes.

Este repositorio conserva, deliberadamente, **solo el aprendizaje de la primera etapa**: no establece lenguaje de programación, motor de almacenamiento, proveedor de alojamiento, formato de intercambio, herramienta de extracción ni arquitectura técnica concreta. El compromiso conceptual es que **la base de información sea el núcleo**; las actividades de lectura/interpretación y la experiencia visual dependen de su contrato.

## Condición del nuevo comienzo

**No se escribe código ni se seleccionan tecnologías antes de demostrar, con casos documentales reales, que el modelo conceptual representa fielmente requisitos, condiciones, evaluaciones, resultados y sus relaciones.** El número de documentos capturados no equivale a integridad ni a utilidad.

El historial de versiones conserva el intento previo para consulta, pero sus decisiones técnicas **no tienen vigencia** en este reinicio. No se heredan implementaciones, datos interpretados ni instrucciones de la etapa anterior por defecto.
